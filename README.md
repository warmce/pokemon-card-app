# Pokemon Card App

This is my attempt at learning how Svelte works, and what better way to do that than making something about Pokemon?

I'm planning on making it a card tracker/pokedex type of thing, but first I need to figure out how to work Svelt properly.

It makes use of the [TCGDex API](https://tcgdex.dev/), more specifically, the JavaScript/TypeScript SDK.

# Features so far:
1. **Home and About pages** - yes yes, very comlplex indeed, there's a landing page and an about page
2. **Random Card generator** - you can click a button and it gives you a completely random card
3. **List of Sets** - a list of every valid set
4. **Individual Set Pages** - displays images of all cards in the set
